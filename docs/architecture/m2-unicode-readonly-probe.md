# M2 Unicode and IME readonly probe

2026-10-03. This probe gathers bounded AX, Core Graphics, kernel process, and TIS facts from one TextEdit process launched by this run. It does not implement or validate TypeText delivery.

## Observable facts

- `TISCopyCurrentKeyboardInputSource` and `TISCopyCurrentKeyboardLayoutInputSource` report different sources. An IME may expose an underlying keyboard layout. Source ID, type, category, mode ID, ASCII capability, keyboard type, and a bounded layout-data digest describe the input environment; none establishes whether text is currently marked. This matches the existing keyboard plan in [m2-native-keypress-plan.md](m2-native-keypress-plan.md).
- The probe separately reads the target process's `AXFocusedUIElement`, `AXFocusedWindow`, bounded AX tree, parent/child membership, and `AXSharedFocusElements`. It compares actual `AXUIElement` references with `CFEqual`, records role and window frame, and correlates the sole visible layer-zero Core Graphics window by frame. A relationship is reported only when the reads establish it.
- The four marked-text attributes are queried individually: `AXMarkedTextRange`, `AXMarkedRange`, `AXHasMarkedText`, and `AXTextInputMarkedTextMarkerRange`. The selected range is recorded separately. Marker values are represented by type and AX error only; opaque marker content is not read.
- The Unicode value read first requires a successful `AXNumberOfCharacters` result no greater than 4096. The value is then reported only when it is at most 16 KiB in UTF-8; larger values are omitted. This is a readback of the prewritten temporary document, not evidence of an input event.
- The launcher writes and hashes one owner- and mode-checked `.txt` file under a fresh system temporary directory, then asks `NSWorkspace` to open only that URL in the fixed system TextEdit bundle. Its `OpenConfiguration` requests a new instance, disables Recent Items, passes `-ApplePersistenceIgnoreState YES`, and activates only that new instance. Before launch it snapshots existing TextEdit PIDs and their kernel start/path facts; the private stdio receipt binds the returned `NSRunningApplication` PID to its kernel start, parent, executable, launch interval, document hash, and launcher identity. A system `launchd` parent is recorded explicitly; probe validation requires the receipt and exact before/after process identity rather than relaxing the target PPID check globally. The launcher closes only the API-returned new instance after rechecking its PID/start/path with `NSRunningApplication.terminate()`.

## Unknowns kept explicit

- Generic cross-process AX does not guarantee that AppKit exposes these marked-text attributes. An unsupported attribute, a missing selected range, or a TIS source name cannot be translated into “unmarked.” The report preserves raw attribute errors and values, keeps the composition conclusion `Unknown`, and never infers composition from selection or TIS metadata.
- `NSTextInputClient.hasMarkedText` and `markedRange` are process-local contracts. The helper cannot call them on TextEdit. `AXSharedFocusElements` is retained as a CF relationship observation; it is not promoted to proof that an element is an AppKit field editor.
- The run must establish that the current system-focused app is this new instance, the focused receiver is uniquely in its AX tree and belongs to the uniquely matched temporary-document window, and the original kernel/process/window facts remain unchanged. Otherwise value and marked-property reads are skipped or reported Unknown. The launch receipt grants no input authority.
- The probe does not send Unicode events, press keys, call AXSetValue/AXPress, change focus, save or reopen the document, or establish how TextEdit routes Unicode events through an IME. TypeText support, saved-document behavior, and the full MVP remain open as described in [complete-design.md](../design/complete-design.md).

## Running

`node scripts/probe-macos-unicode.mjs --build-only` compiles the strict Swift helper and private launcher into a fresh directory under the system temporary directory and does not launch a GUI app. `--protocol-check` exercises the private snake-case stdin command, receipt encoding, and nested probe request decoder without opening TextEdit. `node scripts/probe-macos-unicode.mjs --run` launches and probes one owned TextEdit instance. The report is written to `artifacts/m2-native-unicode-readonly-probe.json`; previous reports are retained beside it. A failed or incomplete run keeps the temporary file, hashes, permission facts, and process output for inspection.
