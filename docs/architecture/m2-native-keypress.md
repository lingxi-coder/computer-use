# 原子 KeyPress 与当前窗口证据

2026-10-03。沿用唯一 `Primitive::KeyPress { key, modifiers }`。本期实现仍在验收中，生产 helper 的键盘能力关闭；首个自有窗口 profile 仅覆盖实际聚焦 `AXCheckBox` 的 `Space`，无修饰键。公开特殊键词汇不等于这些键已经获得原生能力。

## 来源和绑定

`FocusContext` 来自完整 Source 读取中的真实系统/应用焦点、唯一实际 CF 控件、父子关系、固定窗口、完整 fingerprint、内核进程身份和前后复验。`UiObject.focused` 或鼠标命中不能生成键盘权。`FocusedControl` 与普通、菜单、窗口激活输入域互斥；绑定、来源时间、代次、帧期限和许可必须保持当前。

`SourceWindowContext` 独立描述每次完整正常窗口读取的当前内核进程与根窗口，允许没有 focused element。它不授予输入权。按键后的只读读回和重访必须凭新窗口证明核对原进程、窗口、框及当前来源；缺失证明、进程换代、局部读取或不安全祖先都会撤销旧结果绑定。

## 提交和未知结果

Rust 的 KeyPreflight 先发送只读探测，再在原期限内发送完全相同的不可变 packet。原生串行 AX worker 保留探测时实际 receiver/root CF 引用；提交单次消费，并核对当前真实引用。它证明首次 native preflight 到 submit 的连续性，不声明更早跨进程 Source AX 读取到首次 preflight 的 CF 连续性。

系统按键状态扫描后重新检查时钟和许可。down/up 使用同一有序提交门。每对事件带一个内部随机 `CGEventSourceUserData` nonce，只用于区分这对事件，不授予输入权。down 使用 pair 记录的基准戳；精确焦点复验后、commit 前，再从真实 `DispatchTime` 采样 up 候选戳并要求其严格晚于 down。戳无效时在 commit/post 前失败；生产 post 路径中 down/up 连续发送，没有运行时分支或取消检查；专用 death-injection 配置保留有界测试暂停点。tap ACK 要求当前 nonce 的 down→up 顺序、精确键码/类型、无 autorepeat、实际 tap 时间戳为正且 up 严格晚于 down，并在单调接收时间的 `min(post + 150 ms, 原期限)` 内完成。所有当前 SDK 具名 flags 的投影必须等于构造时预期（此 profile 为 0）；完整 raw flags 在 down/up 间必须一致。未命名位仅作为同一对事件的只读一致性事实，不解释、不放行新输入；ACK 不比较 tap 时间戳与发送前赋值的时间戳。最终提交还要通过独立系统按键/鼠标清空与 Guard 期限、停止代次检查。CGEventPost 返回、释放 ACK 和业务效果彼此分开。

preflight 阶段失败确定没有发送输入；atomic packet 发送后失联保持 Unknown。Unknown 隔离整个输入通道，不重放、不发新意图、不因实际值恰好匹配或迟到回执推进导航。历史 MvUCED 的 `isolation=false/channel_isolated=false` 暴露了停止在途提交时只暂时挡住派发的缺口。Core 现已在这一分支立即隔离，迟到 Applied/Rejected/Unknown 保持原 Unknown，未提交队列仍为 Cancelled；AAFuHp/OeWeIO 与后续现场 Unknown 均没有第二次输入提交，查询旧回执保持 Unknown。`m2-keypress-stop-isolation-checks.json` 记录的是私有 guard 收据改动前的测试快照：27 项异步、727 Rust、121 TypeScript、Source 123 pure、format 与 Clippy；这些总数不代表后续私有 guard 变更后的全量结果。当前 guard library 42 项测试与 workspace format/Clippy 通过。私有收据只在 Operator 模式启用，容量 8 条/16 KiB，默认 device packet 保持不变；恢复的系统清空证据仍由受信调用方证明。

## 登记技能和独立验证

自有登记目标 `keyboard-toggle` 使用一次 Space，动作额度为一。Known 输入后重新取得当前只读绑定；独立 `keyboard.value@1 / CurrentUi` 核验实际 Bool、原 kernel/root、输入结束后的来源及完整安全路径。冻结 `goal.required@1 / UiRevisit` 仍需离开并返回的新 UI 读回。输入完成、当前值验证和根完成分别记录。
